# nanopb runtime

Vendored from the nanopb 0.4.9.1 release
(https://github.com/nanopb/nanopb/releases/tag/0.4.9.1): `pb.h`, `pb_common.*`,
`pb_decode.*` and `pb_encode.*`. Only the C runtime is needed during the build.
The generator runs on the host and is described in `main/proto/regenerate.sh`.
